# DatosAbiertos2026 — Gobernanza Pro

## Product Purpose
Transparent audit and ranking of open datasets in Nuevo León's public data portal. Promote data quality through continuous ISO/IEC 25012 evaluation, identify exemplary datasets (Gold standard), and expose technical performance of government agencies. A window into institutional data health.

## Users
- **Government agencies** — CIOs, data custodians evaluating their portal performance
- **Data transparency advocates** — Citizens, researchers, journalists seeking data quality insights
- **Open data practitioners** — Portal managers, data engineers improving data governance
- **Policy makers** — Evidence-based decision making on data infrastructure investment

## Brand Tone
- **Authoritative without jargon** — Technical credibility paired with clarity. Avoid TLAs and corporate-speak.
- **Transparent and open** — Methodology visible, code accessible, no black boxes.
- **Optimistic about improvement** — Highlight leaders (Gold datasets), encourage remediaton, focus on progress.
- **Bilingual confidence** — Equal weight to Spanish and English. No "English default" visual hierarchy.

## Anti-References
- Avoid SaaS dashboard clichés (metrics hero blocks, gradient accents)
- No false urgency or alarm-fatigue language
- Not a scoreboard that shames — frame as diagnostic tool
- Avoid over-design; data visualization should dominate, not chrome

## Strategic Principles
1. **Data-first layout** — Visual hierarchy serves insight, not branding
2. **Accessibility as default** — WCAG AA minimum, bilingual support built-in
3. **Methodological transparency** — ISO/IEC 25012 always visible and explainable
4. **Mobile-first sections** — Government access patterns: mobile-heavy, variable connectivity
5. **Actionable insights** — Rankings, dimensions, methodology drive agency behavior change

## Color Strategy
**Committed palette** — Teal as primary (institutional trust), gold as accent (excellence), midnight for depth, rose for secondary emphasis.
- Primary: Teal (#2a7a6f light, #3aa895 dark mode) — institutional, data-driven
- Accent: Gold (#c8973a, #e4b96a) — quality, excellence (Gold standard datasets)
- Semantic: Midnight (#0f1c2e) — authority, depth
- Secondary: Rose (#b85c6e) — insights, attention without alarm

## Register
**Brand** — Landing page is the primary touchpoint; design drives credibility and user engagement.

## Design Tokens
```
Typography:
  - Serif: Playfair Display (headlines, authority)
  - Sans: DM Sans (body, UI clarity)
  - Mono: DM Mono (data, technical emphasis)

Spacing: 4px grid (4, 8, 12, 16, 24, 32, 48, 64...)
Radius: 0.75rem (12px) — moderate, not rounded
Shadows: Subtle elevation via transparency + soft blur
Motion: Ease-out curves, no bounce
```

## Success Metrics
- Mobile usability ≥80% pass rate (Core Web Vitals)
- Accessibility ≥95% WCAG AA compliance
- Bilingual parity — no "hidden" content in either language
- Agency engagement — rankings drive data publication
