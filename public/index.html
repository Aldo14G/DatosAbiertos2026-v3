Cómo medimos

Siete preguntas sobre cada dataset

Cada conjunto de datos responde siete preguntas simples: ¿Está completo? ¿Es exacto? ¿Se actualiza? El score final te dice si puedes confiar en esos datos. Las dimensiones cumplen el estándar ISO/IEC 25012:2008 — la norma internacional para calidad de datos.

30%

Completitud

¿Tiene el dataset todos los datos? No faltan filas ni columnas. Un dataset 80% completo te deja información importante fuera.

25%

Exactitud

¿Son los números reales? Un dataset tiene exactitud si las fechas son válidas, los números tienen sentido, sin errores obvios.

15%

Consistencia

¿Los datos se contradicen? Si dices que hay 100 registros pero el total suma 50, eso es inconsistencia. Todo debe cuadrar.

10%

Documentación

¿Se entiende qué es? Un buen dataset explica qué contiene, quién lo publica, cuándo se actualiza y si puedes usarlo libremente.

8%

Unicidad

¿No hay repetidos? Si el mismo registro aparece dos veces, eso causa confusión. Todo debe estar una sola vez.

7%

Apertura

¿Puedes usarlo? Un dataset abierto tiene licencia que permite reutilizarlo, está en formato máquina-legible y se puede descargar.

5%

Actualidad

¿Está fresco? Un dataset de hace un año no sirve si necesitas información reciente. Esto mide qué tan actualizado está.

Distribución
Completitud 30% Exactitud 25% Consistencia 15% Documentación 10% Resto 20%

¿Por qué importa esto?

Periodistas necesitan números que puedan confiar para investigar. Investigadores necesitan tablas completas para sus análisis. Ciudadanos necesitan datos actuales para entender cómo gasta el gobierno. Un dataset incompleto o desactualizado es inútil. Esta auditoría te dice cuáles datos SÍ puedes usar y cuáles aún necesitan mejoras.

Para periodistas

Verifica si los datos que encontraste son confiables antes de usarlos en una investigación.

Para analistas

Identifica datasets listos para análisis versus aquellos que necesitan limpieza previa.

Para ciudadanos

Entiende qué organismos publican bien sus datos y quiénes pueden mejorar.
